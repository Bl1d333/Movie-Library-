# Movie Library — Личная кинотека

Графическое приложение на Python для хранения и управления коллекцией фильмов. Позволяет добавлять, удалять и фильтровать фильмы по жанру и году выпуска. Данные автоматически сохраняются в JSON-файл.

## Автор

Матвей Бирюков

## Функциональность

- **Добавление фильмов** с полями: название, жанр, год выпуска, рейтинг
- **Валидация ввода**:
  - Название и жанр — обязательные поля
  - Год — целое число от 1888 до 2030
  - Рейтинг — число от 0.0 до 10.0
- **Фильтрация**:
  - По жанру (выпадающий список доступных жанров)
  - По году выпуска
- **Удаление** выбранного в таблице фильма
- **Сохранение данных** в `movies.json` при каждом изменении
- **Автозагрузка** данных при запуске программы

## Требования

- Python 3.8+
- Стандартная библиотека `tkinter`
- `pytest` (для тестов)
